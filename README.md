# FairFair Farm

เว็บแอปเช็กราคากลางผัก-ผลไม้ สำหรับเกษตรกรรายย่อยใช้ต่อรองกับพ่อค้าคนกลาง
HTML + CSS + JavaScript ล้วน ไม่มี framework ไม่ต้อง build ไม่ต้อง `npm install`

---

## รันในเครื่อง

```powershell
cd "c:\Users\Oilly\ตลาดเงิน"
node server.js          # เปิด http://localhost:3000
```

ต้องใช้ Node.js 18+ (มีแล้วในเครื่อง) · ไม่ต้องใช้ API key ใด ๆ

---

## ขึ้น Vercel

**ผมล็อกอิน Vercel แทนคุณไม่ได้** (ต้องเปิดเบราว์เซอร์ยืนยันตัวตน) ทำ 2 คำสั่งนี้เอง:

```powershell
cd "c:\Users\Oilly\ตลาดเงิน"
vercel login            # เปิดเบราว์เซอร์ ล็อกอินครั้งเดียวจบ
vercel --prod           # ตอบชื่อโปรเจกต์ว่า  fairfair-farm
```

ตอบคำถามที่ CLI ถาม:

| คำถาม | ตอบ |
|---|---|
| Set up and deploy? | `y` |
| Which scope? | บัญชีของคุณ |
| Link to existing project? | `n` |
| Project name? | **`fairfair-farm`** |
| In which directory is your code? | `./` (กด Enter) |
| Modify settings? | `n` |

จะได้ URL แบบ `https://fairfair-farm.vercel.app`
**ไม่ต้องตั้ง environment variable ใด ๆ** เพราะโปรเจกต์นี้ไม่ใช้ API key แล้ว

> อยากผูก GitHub ให้ deploy อัตโนมัติทุกครั้งที่แก้โค้ด:
> `git init && git add -A && git commit -m "FairFair Farm"` แล้ว push ขึ้น GitHub
> จากนั้นกด Import ใน [vercel.com/new](https://vercel.com/new) · `.gitignore` กัน `.env` ไว้แล้ว

## เป็นเว็บแอป (PWA) ติดตั้งลงมือถือได้

| ความสามารถ | รายละเอียด |
|---|---|
| ติดตั้งเป็นแอป | Android/Chrome ขึ้นปุ่ม "ติดตั้งเป็นแอปในเครื่อง" · iOS กด Share → Add to Home Screen |
| ใช้งานออฟไลน์ | `sw.js` เก็บหน้าเว็บ + รายชื่อสินค้า + ราคาไว้ในเครื่อง เปิดได้แม้ไม่มีสัญญาณ |
| แจ้งเตือนออฟไลน์ | แถบสีส้มด้านล่างบอกว่ากำลังใช้ข้อมูลเก่า |
| ไอคอนแอป | PNG จริง 192/512/maskable/apple-touch (สร้างเอง ไม่ติดไลเซนส์) |

**เปิดออฟไลน์ได้ต้องเสิร์ฟผ่าน https หรือ localhost** — เปิดไฟล์ `index.html` ตรง ๆ service worker ไม่ทำงาน (ข้อกำหนดของเบราว์เซอร์) แต่เว็บยังใช้ได้ปกติ

### รองรับมือถือทุกรุ่น

- ปุ่มและช่องกรอกสูงอย่างน้อย **52-56px** นิ้วกดติดแน่
- ช่องกรอกตัวอักษร **ไม่ต่ำกว่า 16px** ไม่งั้น iOS Safari จะซูมเข้าเองตอนแตะ
- `env(safe-area-inset-*)` เผื่อขอบจอมือถือที่มีติ่งหรือมุมโค้ง
- จุดเปลี่ยนหน้าจอ: 760px / 480px / 360px (เล็กสุดรองรับ iPhone SE รุ่นแรก)
- รองรับแนวนอนจอเตี้ย · กันเลื่อนแนวนอนโดยไม่ตั้งใจ

## ข้อมูลมาจากไหน

| ส่วน | แหล่ง | สถานะ |
|---|---|---|
| รายชื่อสินค้า 86 ชนิด / 161 เกรด | [MOC Open Data](https://data.moc.go.th/OpenData/GISProducts) `gis-products` | ✅ ของจริง |
| ราคา 29 ชนิด + ย้อนหลัง 13 เดือน | [ตลาดไท](https://talaadthai.com/products) | ✅ ของจริง |
| ราคา 57 ชนิดที่เหลือ | `mockprices.js` | ⬜ **จำลอง** |
| ราคาจากกระทรวงพาณิชย์ | `gis-product-price` | ❌ **404 ใช้ไม่ได้** |

**ระบุค้าส่ง/ค้าปลีกชัดเจน** — MOC ส่ง `sell_type` มาให้ ป้ายเขียว = ขายส่ง ป้ายเหลือง = ขายปลีก

### endpoint ราคาของกระทรวงพาณิชย์ตายแล้ว

ทดสอบเมื่อ 2 ส.ค. 2569 — `gis-product-price` ตอบ **404 ทุกกรณี**: ตัวอย่างในเอกสารของกระทรวงเอง (`P11001`, ปี 2018), ปี 2024, 30 วันล่าสุด, ใส่ `/` ต่อท้าย, ใส่ `/v1/`, ปลอม User-Agent เป็น Chrome, ลองชื่อ endpoint อีก 5 แบบ
ขณะที่ `gis-products` บนโฮสต์เดียวกันตอบ 200 ปกติ → เซิร์ฟเวอร์ยังอยู่ แต่บริการราคาถูกถอด [เอกสาร](https://data.moc.go.th/OpenData/GISProductPrice) ยังค้างอยู่

> **มุมนำเสนอ:** เข้าทางธีมพอดี — เรื่องเล่าคือ "ฐานข้อมูลราคากลางภาครัฐถูกทำลาย" และของจริงมันพังจริง ๆ

### ข้อมูลจำลองแยกให้เห็นชัด

ทุกจุดที่เป็นข้อมูลจำลองมีป้าย **ลายทางเทา "ข้อมูลจำลอง"** + กล่องขอบประ
ส่วนราคาจริงเป็นป้ายเขียว "ข้อมูลจริง" — กรรมการมองปุ๊บรู้ทันทีว่าอันไหนเป็นอันไหน

## โหมดผู้สูงอายุ

- ปุ่ม **ก** ขยายตัวอักษร 3 ระดับ (18 / 21 / 25px)
- ปุ่ม **◐** โหมดคอนทราสต์สูง (ขาว-ดำ ขอบหนา ตัดเงานุ่มทิ้ง) อ่านได้กลางแดด
- จำค่าไว้ใน `localStorage` เปิดครั้งหน้าไม่ต้องตั้งใหม่

## ที่ยังทำไม่ได้

1. **ผมล็อกอิน Vercel / Flaticon แทนไม่ได้** — ไม่มีเบราว์เซอร์ ไม่มี session
2. **Flaticon** — ถ้าโหลดไฟล์มาวางใน `assets/icons/` แล้วแก้ `CUSTOM_ICONS` ใน `icons.js` ระบบใช้ได้ทันที
3. **ราคา 57 ชนิดเป็นข้อมูลจำลอง** — ติดป้ายกำกับไว้แล้ว
4. **Teachable Machine ยังไม่ได้ต่อ** — ส่งลิงก์/ไฟล์โมเดลมาได้เลย

## อัปเดตรายชื่อสินค้าจาก MOC ใหม่

`catalog.js` สร้างจาก API ของกระทรวงพาณิชย์ ถ้าอยากดึงใหม่ ให้เรียก

```
https://dataapi.moc.go.th/gis-products?sell_type=wholesale
```

แล้วกรองหมวด `ผักสด` / `ผลไม้` (API ตอบช้า 40-60 วินาที เป็นเรื่องปกติของฝั่งกระทรวง)
